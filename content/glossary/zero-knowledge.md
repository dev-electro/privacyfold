## What Makes an Application Zero-Knowledge?

In a true zero-knowledge application, security does not rely on corporate privacy policies or employee promises. It is enforced mathematically:

- Data is transformed or encrypted in client RAM before any potential network boundary.
- Decryption keys are held exclusively by the user and never transmitted to the host.
- Cloud hosting providers only deliver static code bundles.
