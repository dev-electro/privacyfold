## GPU Compute in the Browser

WebGPU replaces legacy WebGL with an API modeled after modern graphics frameworks (Vulkan, Metal, Direct3D 12).

It unlocks massive parallel compute performance for on-device machine learning models (such as image segmentation and audio transcription via ONNX Runtime Web) without requiring cloud servers.
