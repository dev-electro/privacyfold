## Anatomy of a Tracked Link

UTM tags were created by Urchin Software (later acquired by Google Analytics). A typical tracked URL looks like:
`https://example.com/article?utm_source=twitter&utm_medium=social&utm_campaign=launch`

These parameters enable third-party analytics trackers to profile user referral paths. Stripping them preserves link destination while cutting off surveillance links.
