## Security Vulnerability Reporting
If you discover a security vulnerability, privacy leak, or unexpected network request in PrivacyFold:
- Please report it directly via email to `security@privacyfold.com` or open a confidential security advisory on GitHub.
- We review all technical submissions within 48 hours.
