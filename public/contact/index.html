Responsible Disclosure

If you identify a security issue, unexpected network request, or privacy vulnerability in any PrivacyFold tool, please email security@privacyfold.com. We commit to acknowledging all valid vulnerability reports within 24 hours.

Adding Government or Organization Presets

PrivacyFold maintains 87 official passport, visa, and document presets verified against government immigration and corporate portals. If your jurisdiction or organization has updated photo or document requirements, open an issue or pull request on GitHub with the official source URL.
